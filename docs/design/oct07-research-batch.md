## FrugalEvo

实现冷启动、强模型一次生成多策略、弱模型逐策略试跑及排序、固定父程序的反馈重试、改进后重新锚定、岛屿 MAP-Elites 和成本曲线。固定前缀先于动态反馈；统计实际输入/输出 token，未命中的缓存不虚构折扣。

首轮使用公开 Circle Packing 目标（26 个圆），由隔离子进程运行生成的 Python，外部可信几何检查器计分。沙箱无网络、无工作区或模型缓存挂载、只读运行时、CPU/内存/输出/时间限制；沙箱不可用则拒绝执行，不降级为裸 `exec`。公开 checkpoint 替换论文 API 模型，预算单位明确为本地 token 成本单位而非美元，不声称原表格复现。

## Sentry

运行时只接收公开 reasoning/action/observation 和动作合法性信号。无效动作触发 hard repair；LLM 对最近窗口诊断行为失败，按失败类别、标签重合和新近性检索至多 5 条经验，主标签尽量不超过两条。soft repair 后观察至多 10 步，由 reward-blind 模型验证局部恢复；仅已验证恢复可以生成新经验。硬修复不写入 soft playbook。

提供冻结 playbook 的 held-out 对照；模型、检测器和验证器均不得接收最终答案、参考计划或成功标签。验证器错误和无恢复作为实际失败保留，不以完成声明代替效果。
