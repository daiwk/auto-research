## 共同完成条件

- 中文独立论文文档：完整论文信息、原文机制、公式/架构、原文结果、本地结果与边界。
- 可执行入口与真实输入；诊断数据不能包装成官方 benchmark 或能力提升。
- 新 CUDA 路径在 A100/A30 实跑，并提交脱敏且可校验的证据。
- 目录生成与文档检查、相关行为测试、完整质量门槛。
- 单个 PR 的范围、检查和未完成项在交付时逐项核对。

本轮不等同于推进完整审查水位；未核验的检索候选继续留在审查队列。

## 明确未声称完成的部分

这批交付的是论文核心机制与可执行运行路径，不是十二篇论文的原规模 benchmark 复现。短训练结果不能证明方法改善；没有将这些诊断结果接入 Evolve 的能力晋级。Agent 侧采用有明确边界的工具/工作流环境，不冒充官方代码任务；ViMoD 的正式教师标注、论文 checkpoint 和完整评测仍需后续验证；JEV 的闭源论文分数与本地 NanoJev 实测分开呈现。

## 标签与计数路径审查

新增的 fidelity inventory 条目已按角色核对：后训练的答案仅用于外部 verifier、训练 reference loss 和训练结束后的验证评分，不进入学生 rollout 提示；JEV 数据加载器保存 reference，provider request 仅含问题和候选，预测与 reference 在评估器中比较。Hippocam 的 serial、EvoAlloc 的 proposal count、ViMoD 的因果 position 都是运行状态，不单独作为能力证据。行为测试覆盖请求不含标签、工具真实执行、保护未完成轮次、历史经验互斥和角色训练覆盖。
