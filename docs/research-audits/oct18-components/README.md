## 验收合同

- CUDA部分必须真实运行于单张A100或A30；禁止静默回退CPU。保留源码commit、哈希、逐seed结果及脱敏GPU回执。
- CPU协议接口必须实际执行状态转移、故障注入、独立参考及负对照，不能凭静态registry标签判完成。
- 评测策略不读gold。训练专属verifier或note上下文与被测策略隔离；validation决定接纳，test不参与选择。
- 所有组件均为诊断，不进入可晋级Evolve算子；完整实验的高成本决定是终态，不自动重试。
- Diviner的生产效果是观测性cohort关联，不是随机A/B；Memory Mosaics+有Meta作者但注明个人身份研究，不描述为Meta生产模型。
- 原图、中文详情、元数据、三维目录、指标与执行代码必须同步；仅收录论文不制造metrics或receipt。
