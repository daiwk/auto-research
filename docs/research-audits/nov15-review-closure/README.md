- [Google 原文决定](google-primary-reviews.json)确认 Pluralistic Agents 的 Google DeepMind 参与及 TorchTPU 的真实 TPU 依赖，完整实验按成本结案；2D Gum-Net 从独立官方来源补入，原文为指纹稠密配准专题，不混作通用基础模型。Pluralistic Agents 的公开仓库已把旧“身份未明”例外解决，不能继续照搬旧理由。
- [Meta 原文决定](meta-primary-reviews.json)补齐 ForeSpark：Meta/SNU 署名、958K 对话、8卡 B200 训练及8卡服务矩阵，完整实验成本过高不复现。Meta/AMD 微缩格式论文是 MI350X 端到端基准，不因“生产数据/算子”措辞就判成生产随机 A/B。
- [工业原文决定](root-primary-reviews.json)确认 Airbnb OptiCover 与好奇心推荐的真实生产对照，完整私有平台实验不复现。OptiCover 是三项独立的两臂 A/B，不能写成一个三臂试验；搜索 CTR 的非显著结果与 bookers 的显著结果分开。短信风控的留出集/平衡生产评估和 RecMem 的模型计算基准都不等于生产 A/B。
- [Agent 原文决定](agent-primary-reviews.json)区分真实使用、闭环基准、模拟部署和付费多模型实验。五项已知修订及 PATTERN 修订均单独核对，既有 UPTURN v1 组件与测量不被 v2 审查升级或覆盖。

Google 的45页目录实际读取661个URL；与旧450个URL集合对账后读取211个新增详情。该数量不是661篇原文审查。详情仅写年份而无法确认精确身份/日期的相关条目保守归档，而不是据标题拒绝。Meta 六页144个目录URL是有界核对范围，不是全机构无遗漏证明。实际页面、逐记录决定及不可用入口见三份 `*-source-review.json`；[非阻塞例外](exception-archive.json)只在新证据出现时重开，不自动重试。
