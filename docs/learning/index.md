## 论文小卡片汇总

每篇已收录论文都有一张小卡片，集中展示解决的问题、机制摘要和本地实现边界；可以按研究领域筛选，或搜索论文、机构和主题。因成本等原因未复现的论文保留明确说明。

[浏览全部论文小卡片 →](all.md){ .md-button }

小卡片随论文实现文档同步更新，摘要摘自现有文档。论文公开日期用于查找资料；阅读和实验结论以卡片中的来源与边界为准。

## 怎么使用

- **只有 5 分钟**：读一期精选，想一想结尾的场景问题。
- **刚看到一篇新论文**：到小卡片汇总中搜索，先了解机制与本地做到了哪一步。
- **准备选型或做实验**：从卡片进入原论文、完整复现说明和指标。

没读过的卡片留在这里，随时查阅，无需逐篇补完。
